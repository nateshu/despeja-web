# Despeja · página pública

Página de presentación, descargas y política de privacidad de **Despeja**, de Natesoft
(<https://nateshu.github.io/despeja-web/>). Se publica con GitHub Pages desde la rama `main`.

Aquí **no está el código** del programa: es privado. Solo hay HTML, imágenes y, en *Releases*, el
instalador de la edición completa.

- `index.html`: presentación (español o inglés según el navegador).
- `privacidad.html`: política de privacidad (la pide la Microsoft Store).
- `img/`: logo, ícono, foto de fondo y capturas.
